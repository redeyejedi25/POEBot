# Path of Exile 2: The 12 Classes & Attribute Pairing System

Source Reference: Official GGG Announcements & PoE2DB

---

## 1. Class Architecture: 12 Base Classes (6 Attribute Pairs)

Path of Exile 2 completely reorganizes the character roster around **12 base classes**, strictly mapped across **6 attribute pairs** (two classes per combination). 

> **Critical Note (Anti-Hallucination):** The **Scion** class does **NOT** exist in Path of Exile 2.

```
       [ STRENGTH ]
        /        \
  [STR / DEX]   [STR / INT]
      |              |
  [ DEXTERITY ] - [ INTELLIGENCE ]
         \        /
        [DEX / INT]
```

### The 12 Classes Breakdown:

| Attribute Archetype | Class 1 | Class 2 | Primary Weapon & Playstyle Focus |
| :--- | :--- | :--- | :--- |
| **Pure Strength (STR)** | **Warrior** | **Marauder** | Heavy maces, slams, physical stun, high armor, ancestral rage. |
| **Pure Dexterity (DEX)** | **Ranger** | **Huntress** | Bows, agile ranged archery, spears, fast tactical positioning. |
| **Pure Intelligence (INT)** | **Witch** | **Sorceress** | Minions, occult dark magic, elemental spellcasting (Fire, Cold, Lightning). |
| **Strength & Dexterity (STR/DEX)** | **Mercenary** | **Duelist** | Crossbows with ammo loadouts, grenades, rapiers, fencing counters, bleeding. |
| **Strength & Intelligence (STR/INT)** | **Templar** | **Druid** | Flails, shields, holy/elemental melee, shapeshifting (Bear/Wolf) & storm nature magic. |
| **Dexterity & Intelligence (DEX/INT)** | **Monk** | **Shadow** | Quarterstaves, unarmed martial arts, elemental combos, daggers, traps, critical strikes. |

## 2. Starting Locations & The Dual-Spec Passive Tree

* **Shared Tree with Dual Starts:** While each attribute pair shares a general region on the massive passive skill tree, the two classes in that pair have different starting nodes and innate attribute affinities.
* **Dual-Spec Passive Points:**
  * Players earn specialized weapon-swap passive points.
  * For example, a Druid or Sorceress can allocate Fire passives to Weapon Set 1 (Fire Staff) and Cold passives to Weapon Set 2 (Cold Scepter), and the game automatically applies the correct nodes without latency as you use active skills.

---

## 3. Weapon Affinities & Skill Restrictions
* In PoE 2, active attack skills are strictly bound to weapon types:
  * *Crossbow skills* require a Crossbow and use ammunition.
  * *Quarterstaff skills* require a Quarterstaff.
  * *Flail skills* require a Flail and shield.
* Attempting to use a Bow skill with a Melee weapon is impossible due to weapon tag requirements.

## 4. Ascendancies & Version 1.0.0 Roster Finalization
Source: `https://poe2db.tw/Version_1.0.0` and `https://poe2db.tw/us/Ascendancy_class`
* **Detailed Ascendancy Breakdown:** See the dedicated reference document: `knowledge_cache/raw/classes/poe2_ascendancies_and_trials.md`.
* **3 Ascendancies per Class:** Each of the 12 classes possesses 3 ascendancy specializations (totaling 36 ascendancies across the game, including Trial of the Ancestors as a third ascendancy option).
* **Duelist & Swords Debut in 1.0:** The Duelist (STR/DEX) and Swords weapon types (One-Handed and Two-Handed Swords) officially launch into the playable roster with the Version 1.0.0 release on December 11, 2026.
